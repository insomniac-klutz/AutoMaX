# AutoMax
Automatic Maximal Coverage

AutoMaX (`amx`) designs LLM-free pipelines from labelled data, certifies selective risk and coverage per risk band, and hands the unresolved residual to a later LLM phase.

- `HANDOFF.md`: design spec
- `docs/OQ.md`: open questions for the owner
- `docs/ROLLER.md`: rolling build plan and status
